Part 4

For this project I used Python in Google CoLab. The first major step the project performs is printing the available genre options and allowing the user to input either the number of the genre or the name of it. Then, it gets a random suggestion from the list that is assigned to that genre. Next, it prompts the user to indicate whether they have seen the movie before. Finally, if the anser is "y" then it picks another movie from the same genre list, and if the anseer is "n" it returns to the original genre prompt. The user can quit the program at any time by inputing "q". Originally, I had modeled this agent after the to-do list assignment we had I think in 111 or 281. I used the initial draft I created and asked Cursor to make it more concise and fix any errors. Then, I asked it how to implement giving the user the option to say they have seen the movie before. I created the dictionary that holds the genres and movies, the genres variable, the skeleton for display_genres, the skeleton for pick_genre, and the skeleton for suggest_movie. The project overall was fairly understandable for me, the hardest part was making it more concise.
