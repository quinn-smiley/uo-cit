Part 6
Before the packet can start moving from the VM to example.com, the VM uses DNS to translate the name example.com into an IP address, which tells the packet where its going. The first routing decision happens when the VM knows that the destination is outside itself, so it sends the packet to the virtual gateway. As the packet enters the host computer, the host performs the first round of NAT. This is where the VM's private IP stops being used, the host replaces it with its own public IP address because the one from the VM is not globally available. From there, the packet moves to the physical home router, which performs NAT a second time to swap the host's IP for the Router's Public IP address. This public IP is the final global identity provided by the ISP. The ISP then handles the final routing decisions, passing the packet through the internet until it finds the server for example.com. To return, the server sends data back to the public IP, and the router and host use their internal memory to tranlate the addresses back to private and deliver the packet back to the VM.
